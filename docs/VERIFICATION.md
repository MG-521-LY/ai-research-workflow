# 发布验证范围

本次发布检查针对导出的源码仓库；不把原机历史运行结果直接当作新克隆环境的完整验收。

## 本仓库提供的默认检查

```powershell
python scripts\verify_repository.py
python scripts\update_source_manifest.py
python -m unittest discover -s tests -v
python workflow.py doctor --profile research
python workflow.py demo
python scripts\check_empty_corpus.py
```

发布检查核对Python语法、JSON文件解析、必要入口、顶层教程链接、发布清单覆盖/摘要/尺寸，以及禁止随包提交的论文/数据库/授权状态/常见密钥模式。文件范围取自Git已跟踪和未忽略的新文件；忽略的本机outputs、论文和凭据不会被读取，强制加入Git的文件仍受检查。需要Git克隆目录。

自包含回归不依赖原机研究资料。临时生成PDF，覆盖：去重与未知题录、中文/空格路径、相对路径、损坏/缺失/改写文件、重复ID、显式拒收状态、OCR警告、不覆盖已有清单、无依赖诊断、不回显密钥、部分失败状态保留、完成报告字节篡改，以及真实T005解析/索引。子进程拦截网络；不写真实Zotero、不投递DSH。

`demo`只运行真实T005第一阶段，其他阶段保持pending，不生成假模型答案。空语料测试还核对明确的“清单条目为空”原因，避免依赖缺失等其他异常被误算为门禁有效。

GitHub Actions使用Python 3.12，在Windows与Linux运行同一组检查。CI不是完整真实文献、机构授权、模型、实验或科学结论验收。macOS和其他Python版本未列为本次验证平台。

## 需要单独环境的数据回归

学校图书馆路线的默认离线回归包括：首页面身份、参考文献误匹配、不同 DOI 冲突、损坏/扫描 PDF、重复下载、恢复输入变更、文件篡改、未核验项不能冒充完成、签名 URL 脱敏以及无网络计划。2026-10-21 在本机 Windows 额外运行了真实 CloakBrowser：中科大官网及数据库导航可见打开并检查截图；本地合成 PDF 经真实原生下载事件接收、题名/DOI与字节核验通过。这两项独立烟测不涉及学校登录、付费订阅或真实闭源文献，不能视为这些事项已验证，也不在默认离线 CI 中自动打开浏览器。

模块保留已有的回归脚本。部分T003/T005/T006脚本依赖原机的文献样本、缓存、授权会话或本地应用，因隐私和版权未一并分发。它们是历史验证与维护参考，不应在全新克隆后直接宣称通过。尤其T006的历史集成测试涉及真实本机应用，不在默认CI执行。

## 新部署验收清单

- 能在自己的环境安装依赖并执行模块帮助；
- 使用自己合法取得的小批资料，逐一核对身份、版本与实际字节；
- 验证自己的Zotero正常授权、父子附件、幂等重跑和中断恢复；
- 验证实际模型/检索路由、引用定位、证据不足拒答与非零退出；
- 换问题、换资料和网络恢复后的缓存失效/恢复符合本次输入；
- 对关键研究结论回查原文，资源、单位、条件和假说边界诚实保留。

整链执行成功、文献证据充分、研究设计自洽、创新成立与物理实验有效是不同层级，不能互相替代。

## Connector 优先改动的验证

离线检查覆盖来源分流、确定失败/不确定暂停、首个请求中断不重发、父条目精确身份、正常 Local API 的 HTTP 302 登记路径与实际 PDF 字节，以及主题队列、Zotero 衔接和原 fetch 路径。CI 安装本仓库 InstSCI 并在 Windows/Linux 运行这些回归，不在 CI 启动真实 Zotero。

2026-10-21 本机真实验证官方 Connector 5.0.217 在可见 CloakBrowser 加载，驱动扩展自身保存一份明确的合成题录和 PDF，独立 Local API 回读实际附件字节 SHA256 一致；重跑复用原父子项，父条目仍为一个。合成资料不计入科研文献，不证明所有数据库或订阅权限已通过测试。
