# 发布验证范围

本次发布检查针对导出的源码仓库；不把原机历史运行结果直接当作新克隆环境的完整验收。

## 本仓库提供的默认检查

```powershell
python scripts\verify_repository.py
```

检查Python语法、JSON文件解析、必要入口、当前顶层教程链接，以及禁止随包提交的论文/数据库/授权状态/常见密钥模式。它不连接模型、Zotero、DSH或出版商。结果会明确列出实际检查项，不生成虚构科研通过率。

GitHub Actions运行同一静态检查，配合临时空语料门禁检查。CI不是完整真实文献、授权、模型、实验或科学结论验收。

## 需要单独环境的数据回归

模块保留已有的回归脚本。部分T003/T005/T006脚本依赖原机的文献样本、缓存、授权会话或本地应用，因隐私和版权未一并分发。它们是历史验证与维护参考，不应在全新克隆后直接宣称通过。尤其T006的历史集成测试涉及真实本机应用，不在默认CI执行。

## 新部署验收清单

- 能在自己的环境安装依赖并执行模块帮助；
- 使用自己合法取得的小批资料，逐一核对身份、版本与实际字节；
- 验证自己的Zotero正常授权、父子附件、幂等重跑和中断恢复；
- 验证实际模型/检索路由、引用定位、证据不足拒答与非零退出；
- 换问题、换资料和网络恢复后的缓存失效/恢复符合本次输入；
- 对关键研究结论回查原文，资源、单位、条件和假说边界诚实保留。

整链执行成功、文献证据充分、研究设计自洽、创新成立与物理实验有效是不同层级，不能互相替代。
