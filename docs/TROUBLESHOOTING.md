# 故障排查与恢复

| 现象 | 先检查什么 | 处理方法 |
| --- | --- | --- |
| `doctor`列出缺少依赖 | 正在使用的Python解释器与`missing_required` | 在同一解释器安装`requirements.txt`；原生PaperQA另配，不自动切换解释器 |
| `manifest`提示已有输出 | 该清单是否属于已审核/旧任务 | 使用新文件名保留旧记录；命令不会覆盖 |
| `validate`提示OCR或题录待核 | 是否扫描件、题名作者版本是否核实 | OCR及身份核读后再分析；文件检查通过不等精读完成 |
| `status`发现报告hash不符 | 报告是否被修改或来自另一轮 | 保留现场，核对本轮状态与产物；不手改摘要冒充通过 |
| 找不到PDF或语料为空 | 清单绝对路径、文件身份、SHA256 | 修正自己的清单/文件后同目录重跑；不填假路径骗过门禁 |
| 找到题录却没有方法页 | 正文是否真正取得、版本是否一致 | 记录仅题录/缺失，按已有权限补；摘要不改称全文精读 |
| 停在 `awaiting_agent_review` | 上游评审输入与主题相关性 | 宿主完成摘要评审，再继续原任务 |
| 模型401/403 | 当前后端凭据与服务权限 | 修复自己的有效授权；不输出密钥、不静默换模型 |
| 模型429或限流 | 真实服务事件和冷却信息 | 保留产物，遵守服务等待；不循环探测或重送 |
| 网络502/连接失败 | 最新真实错误、任务是否仍活 | 等待外部恢复证据，先查会话/回执，不把旧错当永久不可用 |
| 受控问答拒答 | 当前语料是否支持问题 | 保留拒答与非零退出；补具体缺口或调整问题，不伪造答案 |
| 换问题但结果没变 | 参数是否传入、缓存依赖与输出目录 | 核对本次问题；必要时`--no-resume`，保留旧证据 |
| Zotero授权超时 | 对应worker是否仍等待 | 结束的worker不能因晚到点击算成功；先查状态再决定新流程 |
| Zotero `/file` 返回302 | Location是否为登记附件的本地文件 | 核路径/附件key/文件名并读实际字节hash，不直接判附件不存在 |
| 已有附件被提示失败 | 父子关系、字节摘要、客户端回验错误 | 先真实读回，勿重复建父/上传 |
| 台账或映射损坏 | 原件、历史映射、真实文库 | 保全现场，按恢复入口核实；不清空状态强行重导 |
| 目录被锁 | 持锁进程是否活、是否同任务 | 活锁等待，死锁按恢复规程处理，不删活应用锁 |
| DSH端口改变 | 受信任进程、本机回环与自动发现 | 正常fresh查询；不关闭鉴权、不外网暴露Controller |
| DSH任务受理不明 | request_id回执、inbox、after_seq | 查完再判断；不要换ID盲重发同一任务 |
| 历史回归脚本缺fixture | 真实运行样本是否被排除 | 标注环境依赖，不为跑通而复制私人论文或伪造证据 |

## 推荐保留的诊断信息

保存任务名、时间、后端与模型标识、退出码、去敏后的错误、输入清单摘要、阶段状态和缺口。不要保存Authorization、Cookie、完整密钥、机构口令或包含这些值的进程命令。

## 历史Zotero专项脚本的限制

`goal20/corpus/proposal_story5/zotero_sync_round08.py` 是针对原项目某批文献的工具，保留作源码参考，不是仓库新部署的通用上传入口。它曾将正常本地302文件位置视为回验失败；相关上传不能据这个客户端标志自动重试。使用通用T004入口，专项逻辑若要复用，应先独立核目标计划、授权与回读实现。

## 需要人工决策时

只提出当前确实缺失的信息或权限：例如自己的机构选择、一个实际模型权限、题录身份冲突、需要新增的测量资源。程序状态不能替用户同意新的付费服务、重新发布受版权保护的全文或执行实体实验。
