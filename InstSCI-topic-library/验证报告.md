## 验证结果

1. **29项本地测试通过**。使用明确标识的合成 PDF 与 InstSci 真实清单写入器验证失败补位、目标增减、重复内容、文件丢失/变更、清单损坏、未决批次、身份变化、全局验证暂停、中文 DOI 保留及 Zotero 清单筛选。
2. **真实上游接口解析通过**。实际 `_read_paper_records`、出版社推断、`load_cnki_batch`、`load_wanfang_batch` 和 Typer 参数解析器接受计划生成的输入/参数。当前上游 papers 只逐行读取DOI，因此采用TXT，完整题录另存JSON；多篇DOI批次按实际出版社分组。
3. **真实检索取得3条Crossref题录**。相同请求的Semantic Scholar和OpenAlex返回rate_limited，已按来源保留状态，没有解释为无相关文献。原始结果保存在本机私有运行目录，不随源码发布；三条均保持未评审，下载数为0。
4. **Skill验证通过**。运行 skill-creator 的 quick_validate，输出 `Skill is valid!`。
5. **两宿主安装通过**。每个宿主的6个技能资源与源码SHA-256逐一一致；`runtime/installation.json`记录位置和备份。安装后的命令能够读取真实检索任务。
6. **DSH真实加载通过**。使用本机安装的 filesystem Skill provider，从默认目录发现新技能，验证模型/用户可调用标记及正文资源；记录见 `runtime/dsh-validation.json`。
7. **独立审查通过**。先后发现并修复DOI输入格式、混合出版社批次、中文已知DOI丢失及作者身份过期问题，复核后未发现剩余阻断问题。

## 使用

在 Codex 或 DSH 新对话中说：

> 使用 instsci-topic-library，帮我检索【研究主题】的中英文文献，阅读摘要按【纳入与排除条件】筛选，下载20篇。失败时用下一篇合格候选补足，保留筛选理由和来源。

可直接调整为“总目标30篇”或“再下载20篇”。原 InstSci 技能也已加入主题任务路由提示。若当前技能列表未刷新，保存工作后重开对应应用。建议将运行结果保存在源码仓库之外，每次使用新的任务子目录。
